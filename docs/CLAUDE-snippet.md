# Mac app control

When I ask you to do something inside a Mac app (Notes, Reminders, Calendar, Finder, Calculator, Music, Pages, Numbers, Preview, or any other desktop app), use the `codex-cu` MCP `js` tool (Codex Computer Use through codex-cu-bridge). Prefer it over AppleScript/osascript and over the generic computer-use screenshot tools. First call is always exactly `let app = await cua.getApp("<App Name>");`. Apps not on my allowlist pop an approval dialog on my screen, and Mail, Messages, banking/password apps, Terminal and System Settings ask every time. Wait for the dialog, and never route around a decline.
